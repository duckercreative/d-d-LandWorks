# Google Ads Copy & Creative — HVAC

## RSA Fundamentals

Responsive Search Ads (RSA) are the only active Search ad format. Provide up to 15 headlines and 4 descriptions. Google auto-tests combinations and optimizes.

**Rules:**
- Write all 15 headlines — more combinations = better optimization data
- Pin sparingly — only pin if legally required or brand-critical. Over-pinning defeats RSA's purpose.
- Include keyword in at least 3 headlines — directly improves Quality Score
- Each headline must stand alone — Google may show any 3 together; don't write headlines that only make sense in sequence
- Character limits: Headlines = 30 chars max, Descriptions = 90 chars max

## What NOT to Write

- **Vague:** "Quality HVAC Service" — says nothing
- **Feature-only:** "20 Years Experience" — lead with the benefit, not the credential
- **Duplicate angles:** Don't write 8 headlines all saying "emergency repair" in different words
- **Unverifiable claims:** "Lowest Prices in Houston" — Google may flag this
- **All caps:** "CALL NOW FOR EMERGENCY AC REPAIR" — looks spammy, lowers CTR

## Landing Pages — Requirements per Campaign

Never send campaign traffic to the homepage.

| Campaign | Landing Page URL |
|---|---|
| Emergency AC Repair | /emergency-ac-repair/ |
| AC Repair General | /ac-repair/ |
| AC Installation | /ac-installation/ |
| Maintenance/Tune-Up | /ac-tune-up/ |
| Commercial HVAC | /commercial-hvac/ |

### Required Above the Fold (must be visible without scrolling)
1. **H1 that matches the ad** — If ad says "Emergency AC Repair Houston", H1 must echo that. Never use "Welcome to 75 Degree AC" as H1.
2. **Phone number — large, click-to-call** — Top right corner. Minimum 24px font on mobile.
3. **Trust indicators** — License number, years in business, review count + rating
4. **Primary CTA** — "Call Now" or "Book Online" — one clear action
5. **Service area confirmation** — "Serving Houston, Katy, Sugar Land & Cypress"

### Page Speed Requirements
- Target: Under 2.5 seconds LCP on mobile
- Test: PageSpeed Insights
- Common issue: Oversized images, video backgrounds, slow WordPress themes
- A 4s page vs 2s page = 20–30% higher CPC

### Trust Elements (ranked by conversion impact)
1. Google review count + rating (visible on page) — "4.9 stars · 287 reviews"
2. TACLA license number — displayed: "TACLA12345E — Licensed in Texas"
3. Years in business — "Serving Houston Since 2016"
4. Response time guarantee — "Technician dispatched within 60 minutes"
5. Photos of real technicians/vans (not stock photos)
6. BBB rating / certifications
7. Financing badge
8. Service guarantee — "100% satisfaction or we make it right"

### Mobile CRO (70%+ of emergency traffic is mobile)
- Sticky click-to-call button
- Phone number as FIRST CTA — not a form
- No pop-ups blocking content
- One-tap booking if possible (HouseCallPro, ServiceTitan, Jobber)
- Minimal form fields — name + phone only for emergency

## Conversion Tracking Setup

### What to Track

| Conversion | Type | Value |
|---|---|---|
| Phone call from ad (call extension) | Primary | $75 |
| Phone call from website (via GTM) | Primary | $75 |
| Form submission — contact/booking | Primary | $75 |
| Chat initiated | Secondary | $25 |
| Booking page visit | Secondary | $15 |

Note on value: If 40% of calls become jobs and average job is $400, a call lead is worth $160. Use $75–$150 as conservative starting value.

### Call Tracking — Two Methods

**Method 1 — Google Ads Call Assets (basic)**
- Tracks calls clicking the phone number IN the ad only
- Does NOT track calls from website visits

**Method 2 — CallRail + GTM (recommended)**
- CallRail assigns dynamic tracking number to website
- GTM fires Google Ads conversion when someone calls
- Tracks ALL phone calls from PPC traffic
- Setup: CallRail → number pool → JS via GTM → GA4 + Google Ads goals

**Use both methods together for full call attribution.**

### Form Submission Tracking (via GTM)
1. Create `/thank-you/` page that loads after form submission
2. GTM: Create trigger → Page View → Page URL contains `/thank-you/`
3. Create Google Ads conversion tag firing on that trigger
4. Import into Google Ads or create directly in GTM

### Conversion Settings

| Setting | Value |
|---|---|
| Count | One (not Every) — 1 lead per person, not 3 form submits |
| Click-through window | 30 days |
| View-through window | 1 day |
| Attribution model | Data-driven (if available) or Position-based |
| Include in Conversions | Yes for primary; No for secondary |
| Minimum call duration | 60 seconds (filters hangups) |

### Common Conversion Mistakes
- Tracking page visits as conversions ("Contact page view" is not a lead)
- Counting all calls without 60-second minimum
- Not filtering internal office calls (add office IP as exclusion in CallRail)

## Quality Score Optimization

QS directly affects CPC:

| Quality Score | CPC Impact |
|---|---|
| 10 | -50% vs average |
| 8 | -20% |
| 6 | 0% (average) |
| 4 | +25% |
| 2 | +67% |

A competitor at QS 4 paying $80/click can be outranked by QS 8 at $40/click.

### Three QS Components

**1. Expected CTR** — Write headlines that match the query, use emotional triggers, test urgency words
**2. Ad Relevance** — Include keyword in at least 2 headlines, keep ad groups tight (one theme)
**3. Landing Page Experience** — Match H1 to ad headline, fast load speed, mobile-friendly, clear service confirmation

### Diagnose QS Issues
- QS 1–3: Landing page problem — check relevance and speed
- QS 4–5: Ad relevance — confirm keyword appears in headlines
- QS 6: CTR problem — test stronger headline angles
- Any keyword at QS ≤ 4 after 100+ impressions: pause + fix
