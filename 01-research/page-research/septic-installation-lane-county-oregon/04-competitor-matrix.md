## Braun's Dedicated Install Page — Key Finding [UPDATED 2026-09-24]

Braun has a dedicated installation-and-repair subpage (`braunexcavating.net/installation-and-repair`) listing these Lane County communities: Eugene, Springfield, Junction City, Creswell, Veneta, Lowell, Cottage Grove, Pleasant Hill, and surrounding areas. Braun explicitly lists "new construction" as a system type they install. **However, Braun displays no DEQ certification number anywhere on their site** — notable given that DEQ certification is legally required to install septic systems in Oregon. This is a trust signal gap D&D can exploit by prominently displaying both CCB #261742 AND their DEQ credential.
