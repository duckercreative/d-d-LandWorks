# Intent Triangulation — Utility Excavation (`/utility-excavation/`)

Sourced from general homeowner-forum patterns (TractorByNet, Mike Holt electrical forums, HomeAdvisor/Angi cost-guide comment patterns, Quora), reasoned analogously to the methodology used in all eight prior packs given this project's continued inability to directly query Reddit/live AI chat interfaces. Utility trenching is a narrower, more technical buyer moment than general excavation, and the pain points below reflect that.

---

## Table 1 — Pain Points

| Pain point | Source pattern | Severity | Addressed in our content? |
|---|---|---|---|
| Not knowing how deep a specific utility needs to be buried before calling anyone | Quora/forum "how deep should I bury X" questions, extremely common and utility-specific (different answer for water vs. electrical vs. gas) | High | Yes — the per-utility depth table is this page's central asset |
| Confusion over who calls the utility company vs. who digs the trench | General municipal-utility FAQ pattern; homeowners assume "the contractor handles everything" | Medium-high | Yes — honest, hedged coordination-role section |
| Fear of hitting an existing unmarked line while trenching for a new one | Universal excavation-liability fear, reused from the excavation pack's own Oregon811 finding, sharpened here since utility trenching runs directly parallel to existing utility corridors | High | Yes — Oregon811 cross-linked, applied specifically to utility-adjacent trenching |
| Cost anxiety over trenching under existing hardscape (driveway, patio, sidewalk) vs. open ground | HomeAdvisor/Angi cost-guide comment pattern consistently separates "dirt" vs. "asphalt" vs. "concrete" trenching costs by a 2-3x multiple | High | Yes — cost section should separate surface type as a real cost driver, sourced generically (no Lane-County-exact figures fabricated) |
| Not realizing multiple utilities could go in one trench and save money | Zero competitor mentions this; a genuinely unprompted-need pain point homeowners don't know to ask about until told it's an option | Medium | Yes — joint trenching is a named, explained section |
| Worry that a shallow-looking trench isn't "really" up to code | General code-anxiety pattern common to any buried-utility work | Medium | Yes — citing exact code sections (OPSC/ORSC/NEC) directly answers this |

## Table 2 — Decision Triggers

| Trigger | Context | Maps to |
|---|---|---|
| New construction or ADU needing fresh utility service | Building a structure with no existing utility hookup | Water/sewer/electrical/gas trenching section, cross-linked to Site Preparation |
| Upgrading an existing electrical service (e.g., adding a sub-panel to a shop) | Homeowner adding a detached structure | Electrical conduit depth section |
| A failed or aging existing line needing replacement, not a new run | Different buyer moment than new construction — repair/replace framing | Note this distinction explicitly; do not assume every visitor is doing new construction |
| A property without existing gas service wanting to add it | Utility-expansion buyer moment | Gas line depth + NW Natural coordination context |
| Multiple new utilities needed at once (e.g., a new shop needing water, power, and possibly gas) | The joint-trenching buyer moment | Joint trenching section — directly answers "can I save money doing these together" |

## Table 3 — Trust Killers

| Trust killer | Rebuttal to build into the page |
|---|---|
| No competitor states a single depth figure, so buyers can't tell who actually knows the code | Publish the full per-utility depth table with exact code citations (OPSC/ORSC/NEC), sourced and dated |
| Fear of hidden costs when hitting hardscape (driveway/concrete) mid-trench | Name the real cost differential between dirt, asphalt, and concrete trenching honestly upfront, generically sourced |
| Utility-strike liability fear, sharpened for utility-adjacent trenching specifically | Restate D&D's Oregon811 practice (reused from the excavation page) applied directly to the utility-trenching context |
| Confusion about who's responsible for what in a new hookup | State plainly and honestly what D&D scopes (the trench, bedding, and backfill) vs. what the utility company itself handles (the tap/connection at the main), with the coordination-role caveat properly hedged per `07-oregon-authority.md` §3 |
| No visible acknowledgment that joint trenching is even an option | Name it explicitly as a real, code-permitted, cost-saving option, with the honest utility-company-separation-spec caveat intact |
