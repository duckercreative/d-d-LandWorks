## What "goes deeper" looks like, confirmed by this competitor pass

The already-shipped Excavation & Grading page's sentence — "See foundation excavation for more depth on this project type" — is now backed by a genuine, verified content gap rather than a promise with nothing behind it. Specifically, this page can do five things that literally nothing else found in this research, local or national, currently does all at once:

1. State the actual Oregon frost-depth figure (12 inches for Lane County) with a real code citation, where even the best existing Oregon-specific content declines to.
2. Distinguish slab, crawlspace, and basement foundation types by excavation depth and cost, something only one non-local source (Cojo Asphalt) does at all, and no Lane County contractor does.
3. State a specific over-dig/working-space figure (2 feet minimum, per OSHA's house-foundation/basement carve-out) rather than a vague "we leave room to work."
4. Explain the excavate → inspect → pour sequencing with the actual Eugene/Lane County inspection process, something zero sources found in this pass explain clearly.
5. Name the foundation drain and crawlspace vapor-retarder code requirements, entirely unaddressed anywhere in this research.
