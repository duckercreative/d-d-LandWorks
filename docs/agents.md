# Specialist Agents

Agents are auto-invoked by slash commands, or can be called directly.

| Agent | Specialization |
|-------|---------------|
| `technical-analyst` | Crawlability, indexing, CWV, schema, AI crawler access |
| `content-analyst` | Content audit, gaps, E-E-A-T, citability, content creation |
| `local-seo-analyst` | GBP, citations, reviews, reputation, local pack |
| `keyword-analyst` | Keyword research, on-page SEO, entity audit, cannibalization |
| `offpage-analyst` | Backlinks, social media, CRO, trust signals |
| `ai-visibility-analyst` | AI citations, GEO, voice search, brand SERP, llms.txt |

Each agent reads the relevant SKILL.md file from `.claude/skills/` as its methodology guide. See [skills.md](skills.md).
